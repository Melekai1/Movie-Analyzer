# Movie Analyzer #

This project is a website that analyzes a set of box-office data for several movies. The data can be organized according to different categories, such as sorting by name, domestic gross, 
foreign gross, and worldwide gross. In addition, the user can search for a specific movie that is in the list, and get its box-office data. The user can also search for movies that were 
distributed by a specific studio. 


## Languages/Tools Used ##
- HTML
- CSS
- JavaScript
- Python/Flask


## How to Run ## 
1. Clone this repository, and open it in Visual Studio Code
2. Create a Python virtual environment
3. Make sure Flask is installed, along with other related Python libraries (pip install library-name)
4. Open the terminal and go to the "movie-analyzer" folder (cd movie-analyzer)
5. Run the program (python app.py)
